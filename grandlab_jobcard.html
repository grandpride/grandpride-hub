Google Sheets sync
Connect Google Sheets
Each car plate gets its own sheet tab
Setup steps (one time, 5 min)
  1. Open your Google Sheet → Extensions → Apps Script
  2. Delete all code, tap Copy Apps Script below and paste it in
  3. Deploy → New deployment → gear icon → Web app
  4. Execute as: Me   Who has access: Anyone
  5. Deploy → Authorize → Allow → copy the /exec URL
  6. Paste URL below and tap Save URL
Share with staff
How to share with staff
All staff use the same Netlify URL
  1. Upload index.html to app.netlify.com/drop
  2. Share the Netlify link to all staff via WhatsApp
  3. Each staff: open in Chrome/Safari → Share → Add to Home Screen
  4. Each staff: go to Setup → paste the same Google Sheets URL → Save
Photo storage (ImgBB)
Connect ImgBB photo storage
Free · no size limit · photos save as links in sheet
Setup (2 minutes, free):
  1. Go to imgbb.com and sign up free
  2. Click your profile → API
  3. Copy your API key
  4. Paste it below and tap Save
Photos upload instantly to ImgBB. Links are saved in Google Sheet so you can view anytime.
